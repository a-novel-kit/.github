# Developing A-Novel

The developer guide lives at **[a-novel-kit.github.io/stack](https://a-novel-kit.github.io/stack/)**. It takes a fresh machine to a working setup: each tool per operating system, the access to request from the team, then the [`a-novel` CLI](https://github.com/a-novel-kit/stack) with a runbook per task. One setup covers both organizations, [`a-novel`](https://github.com/a-novel) and [`a-novel-kit`](https://github.com/a-novel-kit).

The guide's source is the stack repository's [`docs/`](https://github.com/a-novel-kit/stack/tree/master/docs) directory; change it there.

## Getting help

- Questions and discussion: join us on [Discord](https://discord.gg/rp4Qr8cA).
- Bugs and feature requests: open an issue on the affected repository.
- Security reports: **never** a public issue — follow the
  [security policy](https://github.com/a-novel-kit/.github/blob/HEAD/SECURITY.md).
